پلتفرم هوشمند املاک و مستغلات برای WordPress.

== Installation ==
1. فایل ZIP را از GitHub دریافت کنید.
2. اگر نام پوشه پس از استخراج realestate-ai-main بود، آن را به realestate-ai تغییر دهید.
3. پوشه را در wp-content/plugins/ قرار دهید یا ZIP را از بخش افزونه‌های وردپرس نصب کنید.
4. افزونه را فعال کنید.

نکته: افزونه برای اجرای پایه، در صورت نبود vendor/autoload.php از autoloader داخلی استفاده می‌کند. برای نصب وابستگی‌های Composer در محیط توسعه، composer install را اجرا کنید.
